# 现金流与桑基图计算口径

本文说明当前实现的业务口径。计算以 `backend/services/stats_engine.py`、`backend/routes/v1_dashboard.py` 和相应回归测试为准。

## 数据范围与币种

- 仅统计当前用户有权读取、已激活且已纳入报表的账户。
- 日期采用页面选定的自然月、季度、今年、最近半年或自定义范围；点击图表进入交易列表时保留该范围和用户筛选条件。
- 原始交易金额、固定账户入账金额与报表展示金额分别保存或计算。页面刷新不会重新估算历史账户余额。
- 跨账户报表统一使用用户设置的展示币种。日汇率先查询数据库，缺失时获取对应日期的报价并保存。
- 图表标签、坐标、提示框和 SVG 金额均随展示币种改变；隐私模式隐藏金额，保留百分比。

## 收入与支出

内部转账、信用卡还款与贷款本金偿还不计入真实外部收入或日常消费。贷款利息与手续费属于支出；未来计划及待换汇记录不影响已入账余额和报表。

账户余额由已入账活动按资金方向汇总；主卡合计包含授权范围内的自身和副卡活动。主副卡同时纳入报表时，各笔活动只计一次。

## 退款与分类守恒

`compute_netted_category_distribution(...)` 统一计算仪表盘和统计报表的分类净额：

```text
分类净额之和 = 消费毛支出 - 本期退款冲抵
```

- 已关联退款回到原消费的分类，支持原消费拆分和跨期间退款。
- 未关联退款使用退款自身的分类。
- 跨币种冲抵依据已保存的原币分配与记账金额，汇差由 `refund_money.py` 处理，不能把实际到账金额重复计入余额。
- 分类净额可以为负数，总净支出也可以为负数；计算阶段不截断为零。
- 舍入尾差归入金额绝对值最大的分类，保证分类合计与总净额一致。
- 饼图占比以正数分类净额小计为分母；负数退款调整的占比为零。百分比合计按舍入尾差调整至 100%。

## 桑基图展示

数据由仪表盘接口的 `cashflow` 返回：

| 字段 | 当前含义 |
| --- | --- |
| `income_sources` | 当期真实收入来源 |
| `pool.amount` | 总净支出为正时使用该值，否则为零 |
| `expense_destinations` | 金额为正的分类净支出 |

桑基图不绘制负宽度的分支，因此不把负数退款分类直接画成流出。存在负数分类时，正数分支小计与带符号的总净支出可能不同；业务金额核对应使用完整分类净额与报表总计，不能把图形宽度当作账本金额。

金额格式化使用 `chartMoney`，图形路径与宽度始终基于数值，不能把格式化文本、货币符号或隐私占位符传入计算。

- `backend/tests/test_fixed_booking.py`：固定金额入账、退款与跨币种主副卡。
